TradingPro – Installationsvejledning

Denne korte vejledning beskriver, hvordan TradingPro køres lokalt.

Forudsætninger
- .NET SDK
- Node.js og npm
- PostgreSQL and Timescaledb Extension
- Git

1. Database
Kontroller, om appsettings.json findes. 
Da appsettings.json ikke findes på GitHub, bedes du oprette den i controller-projektet. 
Hele appsettings.json kan findes nederst i dette dokument.
Kør derefter de eksisterende migrations:

update-database

Ved udvikling kan en ny migration oprettes med:

Add-Migration InitialTradingAppDb
update-database

2. Backend
Gendan pakker og start API'et:

dotnet restore
dotnet run

3. Frontend
Åbn en ny terminal:

cd tradingappfrontend
npm install
npm run dev

4. Test og kontrol

dotnet test
npm run build
npm run lint
